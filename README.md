# 🔗 PocketURL

> **Shorten. Share. Simplify.**

A modern and responsive URL shortener built with **HTML, CSS, and JavaScript**, powered by the **TinyURL API**. PocketURL focuses on delivering a clean user experience with beautiful animations, QR code generation, URL statistics, dark mode, and smart history management.

---

## ✨ Features

- 🔗 Shorten long URLs using TinyURL API
- 📋 One-click copy to clipboard
- 🔗 Open shortened URL in a new tab
- 📱 Generate QR Code for every shortened URL
- ⬇️ Download QR Code as PNG
- 🌐 Live website favicon preview
- 📊 URL statistics (Characters Saved & Compression)
- 📝 Recent history with Local Storage
- 🔍 Search through history
- 🕒 Relative timestamps (Just now, 2 mins ago, etc.)
- 🚫 Duplicate history prevention
- 🌙 Dark / Light Mode
- 📱 Fully Responsive Design
- ✨ Smooth animations and glassmorphism UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PocketURL.git
```

Open the project

```bash
cd PocketURL
```

Run using the VS Code **Live Server** extension or open `index.html` directly in your browser.

---

## 🔑 API Setup

PocketURL uses the TinyURL API.
1. Create a TinyURL account.
2. Generate your API key.
3. Open `script.js`.
4. Replace:

```javascript
const API_KEY = "your_api";
```

with your own TinyURL API Key.
