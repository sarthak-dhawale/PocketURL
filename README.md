# 🔗 PocketURL

> **Shorten. Share. Simplify.**

A modern URL shortening web application built using **HTML, CSS, JavaScript**, and the **TinyURL API**.

PocketURL transforms long URLs into short, shareable links through a clean and responsive interface inspired by modern SaaS applications.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PocketURL.git
```

Open the project

```bash
cd PocketURL
```

Run using **Live Server** in VS Code.

---

## 🔑 API Configuration

Create your TinyURL API Token.

Inside `script.js` replace

```javascript
const API_KEY = "YOUR_API_KEY";
```

with your own API key.

⚠ Never upload your real API key to GitHub.
